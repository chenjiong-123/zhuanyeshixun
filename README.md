# 智能英语作文批改系统

这是一个面向英语写作练习的离线批改原型。系统从内容与切题、结构与衔接、词汇运用、语法与规范、篇幅与格式五个维度生成 100 分制结果，并给出问题定位、规则修订稿和优先改进建议。

项目为“计算机科学与技术 / 计科中外1班 / 陈炯”的专业综合实训成果，日期为 2026 年 9 月 26 日。

## 一、快速启动

环境要求：Windows 10/11，Python 3.9 或更高版本。运行核心项目不需要安装任何第三方库，也不需要网络或外部 AI 接口。

### 方法 A：双击启动

双击 `启动系统.bat`。看到“系统已启动”后，浏览器会自动打开：

`http://127.0.0.1:8000`

关闭控制台窗口或在控制台按 `Ctrl+C` 即可停止系统。

### 方法 B：命令行启动

在项目目录打开终端，执行：

```powershell
python app.py
```

如果 8000 端口被占用，可执行：

```powershell
python app.py --port 8010
```

## 二、使用流程

1. 在“单篇批改”页选择一篇示例作文，或自行输入题目、写作任务和英文正文。
2. 点击“开始智能批改”。
3. 查看综合得分、五维分数、文本统计和优先改进建议。
4. 向下查看逐条问题定位及规则修订稿。
5. “批量评测”页可一次运行 12 篇匿名测试作文；“评分说明”页展示维度与分值。

输入少于 20 个字符或有效英文单词少于 5 个时，系统会给出提示而不执行评分。

## 三、评分规则

| 维度 | 满分 | 主要依据 |
|---|---:|---|
| 内容与切题 | 25 | 题目关键词覆盖、观点回应、例证与原因说明 |
| 结构与衔接 | 20 | 段落数、衔接词、开头观点与结尾总结 |
| 词汇运用 | 20 | 实词多样度、高级词汇、长词比例和重复度 |
| 语法与规范 | 25 | 主谓一致、动词形式、冠词、拼写、大小写、标点 |
| 篇幅与格式 | 10 | 120—260 词建议区间和自然分段 |

本系统使用可复现的离线规则与文本统计，不调用生成式模型。结果适合学习反馈和演示，不替代教师对立意、文化语境及复杂句法的最终判断。

## 四、测试与评估

执行全部自动化测试：

```powershell
python -m unittest discover -s tests -v
```

执行测试集评估并生成 `docs/evaluation_results.json`：

```powershell
python evaluate.py
```

测试覆盖评分结果结构、常见错误检测与修订、短文本校验、全部样例可评分、健康检查接口和批改接口。

## 五、项目结构

```text
├─ app.py                 本地网页服务器与 API
├─ grader.py              批改算法、评分与修订规则
├─ repository.py          测试数据读取
├─ evaluate.py            测试集量化评估
├─ 启动系统.bat            Windows 启动脚本
├─ data/
│  └─ sample_essays.json  12 篇匿名测试作文及参考分
├─ static/                网页界面文件
├─ tests/                 自动化测试
└─ docs/                  评估结果、截图与演示材料
```

## 六、常见问题

- **双击后窗口一闪而过**：确认已安装 Python 3.9+，安装时勾选“Add Python to PATH”。也可在项目目录的终端中执行 `py -3 app.py` 查看完整提示。
- **浏览器没有自动打开**：手动访问 `http://127.0.0.1:8000`。
- **提示端口被占用**：使用 `python app.py --port 8010`，然后访问 `http://127.0.0.1:8010`。
- **中文路径是否影响运行**：项目已按中文路径测试；启动脚本使用自身目录作为工作目录。
